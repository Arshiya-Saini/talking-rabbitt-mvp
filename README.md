# Talking Rabbitt MVP

Talking Rabbitt is a conversational AI analytics prototype that allows users to interact with business data through natural language queries.

## MVP Objective

The goal of this MVP is to demonstrate the "Magic Moment" of Talking Rabbitt, where a user can upload business data and instantly get insights through a conversational interface.

## How It Works

1. The user uploads a CSV dataset.
2. The user asks a natural language question about the data.
3. The system analyzes the dataset.
4. The application returns a response and generates a visualization.

Example query:
"Which region had the highest revenue?"

The system then generates insights and visual charts based on the uploaded data.

## Tech Stack

- Python
- Streamlit
- Pandas
